# 📌 Project TFU Jira – Task & Project Management System

## 📌 Description
Le **Project TFU Jira** est une application de gestion de tâches et de projets inspirée de Jira.

Ce système permet de planifier, organiser et suivre les tâches d’un projet de manière structurée, en utilisant une approche similaire aux méthodologies Agile (Scrum / Kanban).

L’objectif est de reproduire les fonctionnalités principales d’un outil de gestion de projet professionnel comme Jira, afin de mieux comprendre les systèmes de productivité en équipe.

---

## 🎯 Objectifs du projet

- Reproduire un système de gestion de tâches type Jira
- Organiser les projets en tickets (tasks, bugs, features)
- Améliorer le suivi des activités d’équipe
- Appliquer les principes Agile / Scrum / Kanban
- Comprendre les systèmes de workflow modernes

---

## ⚙️ Fonctionnalités

- 📋 Création et gestion de tâches (tickets)
- 👤 Attribution des tâches aux utilisateurs
- 📊 Suivi de l’avancement des projets
- 🗂️ Organisation en projets / boards
- 🔄 Mise à jour du statut des tâches (To Do, In Progress, Done)
- 🧠 Gestion de workflow inspirée de Jira
- 🔎 Filtrage et recherche des tâches

---

## 🧠 Technologies utilisées

- Python

---

## 🏗️ Architecture du projet

Le système est structuré autour de :

- 📌 Modules de gestion des projets
- 📌 Modules de gestion des tâches (tickets)
- 📌 Workflow de suivi (Kanban / Scrum)
- 📌 Base de données relationnelle
- 📌 Interface utilisateur ou API backend
